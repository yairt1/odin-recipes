# Practicing HTML

Creating html file the will show some recipes

In this project i will use these tags in html:

- **html boilerplate** - enter **!** in vscode to print html boilerplate
- **p** - paragraph tag for writing text
- **h1/h2/h3/h4/h5/h6** - heading tags for creating titles
- **strong** - making text **bold**
- **em** - making text _italic_
- **ul** - making an unordered list (bullet point list)
- **ol** - making an ordered list (numbered list)
- **li** - adding a list item to an ul/ol
- **a** - anchor tag for url links and relative file links, using the **href** attribute, and **target="\_blank"** and **rel="noreferrer"** for opening a link in a new tab
- **img** - image tag to show images in the site, using to **src** attribute for the path of the image, **alt** attribute for describing the file, and **height** and **width** to set the image dimensions
